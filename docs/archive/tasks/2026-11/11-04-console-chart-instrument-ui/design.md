# 海图仪表 — 视觉设计

## 1. 主张

**墨色表示位置，颜色表示要不要你动手。**

- 位置（第几段、哪一步、多久）一律用墨色深浅与刻度表达；
- 颜色只回答一个问题：这件事现在需不需要人。四个语义色各只对应一种行动：
  琥珀 = 需要你、海蓝 = 正在进行、苔绿 = 已收尾、铁锈 = 异常。
- 颜色只以两种形态出现：**2px 竖线**（标记「这里」）与 **7px 方块**（标记状态）。
  不再有填充胶囊、浅色底徽章、彩色描边。

名字取自 Keel（龙骨）与海图：冷纸、墨线、测深刻度；不调用任何航海装饰图形。

## 3. 字体

```
--sans: "Avenir Next", "Avenir", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
--mono: "SF Mono", SFMono-Regular, Menlo, Consolas, monospace;
```

- Avenir Next 提供与 SF 不同的几何性格（圆形字碗、明显的人文字形），中文回落 PingFang SC。
- **等宽只给机器事实**：ID、分支、命令、JSON、diff、事件码。正文、数字、元信息一律 Avenir + `tabular-nums`。
- 层级：品牌字标 11px/600/字距 .16em；页标题 19px/600；摘要 13.5px；列表 12.5px；元信息 11px；机器码 10.5px。

## 4. 结构

```
┌──────────────────────────────────────────────────┐
│ ◈ KEEL            概览  任务  项目     主题 刷新 │  masthead 48px
├────────────────┬─────────────────────────────────┤
│ 搜索            │ 项目名                          │  view-head
│ 全部 运行中 …   │ 一句话现状                      │
│ ──────────────  │ 5 个任务，21 轮，$1.68，14:19   │
│ ▌keel-demo     │ ─────────────────────────────── │
│  ■ 2 待处理    │ ▌需要你处理  2                  │  group（2px 信号竖线）
│  5 个任务…     │ ■人工评审 demo3  ▮▮▮▮▮▮▮▮▯▯  去决策
│                │ ■人工评审 demo2  ▮▮▮▮▮▮▮▮▯▯  去决策
├────────────────┴─────────────────────────────────┤
│ ● 已连接  2 运行中  2 待介入         自动刷新 5s │  statusbar 26px
└──────────────────────────────────────────────────┘
```

- 侧栏 272px，冷纸底；主内容 `--panel`；两者之间 1px 规则线。
- 选中项 = 2px 墨色左竖线 + `rgba(18,24,29,0.05)` 底；不再用蓝色填充。
- 筛选项从胶囊改成**文字 + 计数**，激活项加 1.5px 墨色下划线。
- 项目页「需要你处理」组包一条 2px 琥珀竖线；这是页面唯一的整组着色。

## 5. 组件规格

| 组件 | 规则 |
|---|---|
| 状态标记 `.badge` | 7px 方块（`::before`）+ 12px 中文 + 10.5px 机器码；无底色、无圆角、无脉冲 |
| 驾驶模式 `.mode-pill` | 与状态同构的方块 + 文字，不加边框 |
| 按钮 `.act-btn` | 2px 圆角，1px `--rule-strong`；主操作墨色填充 + 纸色文字；拒绝用铁锈色文字 + 描边 |
| 链接 | 墨色 + 1px 下划线（偏移 3px）；hover 转琥珀 |
| 输入框 | 2px 圆角，`--panel-2` 底，1px `--rule`；focus 用 1.5px 墨色描边，不用蓝色光晕 |
| Tab | 文字 12px；激活项墨色 + 2px 下划线；计数 `--ink-3` |
| 表格 / 事件 | 表头 10.5px `--ink-3` 字距 .04em；行分隔 1px `--rule`；无斑马纹 |
| 代码块 | 2px 圆角，`--code-bg`，1px `--rule`；不要阴影 |
| 位置刻度 `.ladder` | 10 段，4×8px，间距 3px，无圆角；已走 `--ink-3` 40%，当前 `--ink`（闸门当前段 `--signal`，异常 `--bad`，走完 `--good`），未走 `--rule` |
| 底部状态栏 | 26px，`--ink-3`；运行数用 `--move`、待介入用 `--signal`；健康点改成 6px 方块 |

## 6. 动效与可访问性

- 删除状态点的 `pulse-ring` 无限动画；只保留 120ms 的颜色/背景过渡。
- `:focus-visible` 统一 1.5px `--signal` 外描边，偏移 2px。
- 保留 `prefers-reduced-motion` 覆盖。
- 颜色不是唯一信息：状态始终带文字，位置刻度的 `title` 给出「主路径第 N / 10 段」。

## 7. 文案

- 元信息用中文逗号成句：`5 个任务，21 轮，累计 $1.68，最近更新 11-04 14:19`。
- 侧栏摘要：`5 个任务，2 个在跑`，时间右对齐单独一列。
- CTA 去掉箭头：`去决策` / `去回答`。
- 标题：`Keel · 工程运行时控制台`。
- 状态机里的 `A → B`、`/` 分隔保持原样：那是事实方向，不是装饰。

## 8. 兼容与回归面

- 状态集合、`statusKind`、`isGateStatus`、分组、筛选口径全部不动。
- SVG 图标保留，只调描边粗细与透明度。
- 暗色主题沿用 `data-theme` + `prefers-color-scheme` 两套入口，token 值成对维护。
- 窄屏：侧栏 260px（≤1024），≤900 上下堆叠。
