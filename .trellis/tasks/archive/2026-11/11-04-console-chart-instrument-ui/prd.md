# 控制台视觉重做：海图仪表

## 背景

控制台（`src/cli/console-page.ts`）当前视觉是 macOS 系统色板 + 通用 dev tool 外壳：
`#0a7aff` / `#f5f5f7` / SF Pro、圆角胶囊徽章、浅色底、`·` 拼接的元信息、`→` 结尾的 CTA。
这套语言与 Keel 自己是什么没有关系，读起来像模板生成的页面。

## 目标

把视觉身份建立在产品自己的事实上：**墨色表示位置，颜色表示要不要你动手**。

- 建立一套只属于这个控制台的设计 token（冷纸 / 墨 / 琥珀信号 / 海蓝进行 / 苔绿完成 / 铁锈异常）。
- 状态从「圆角胶囊 + 浅底」改成「方块 + 文字」，颜色只出现在 2px 竖线与 7px 方块上。
- 位置用墨色刻度条（10 段主路径），与颜色通道分离。
- 排版建立显示级层级：标题 19px、正文 12.5px、元信息 11px，不再 11–13px 平铺。
- 文案去掉机器拼接感：元信息用中文逗号成句，CTA 去掉 `→`。
- 明暗双主题都成立；窄屏、键盘焦点、减少动效继续可用。

## 范围

- `src/cli/console-page.ts` 的全部内联 CSS 与相关渲染标记（侧栏、项目页、任务页、概览、详情各 Tab）。
- 文案调整限于元信息行、CTA、标题。
- `.trellis/spec/frontend/console-guidelines.md` 增加视觉系统章节。
- `src/cli/console.test.ts` 增加 token / 结构断言。

## 非目标

- 不改任何数据接口、查询、状态机、写端点。
- 不改信息架构（上一轮已定：先答「有没有事等我」）。
- 不引外部字体 / CDN / 依赖：只能用系统字体。
- 不改 5s 轮询、Hash 路由、筛选口径。

## 验收标准

- [ ] 页面里不再出现 macOS 系统色（`#0a7aff` / `#f5f5f7` / `#ff9f0a` / `#30d158` / `#ff453a`）。
- [ ] 状态徽章没有圆角、没有填充底色；`S-*` 仍以「中文在前、机器码在后」出现。
- [ ] 元信息行不再用 `·` 拼接；CTA 不再带 `→`。
- [ ] 项目页首屏仍是「需要你处理」第一组，颜色语义不变。
- [ ] 明暗两种主题下正文 / 次级 / 信号色对比度 ≥ 4.5:1。
- [ ] 1024px 与 900px 无横向溢出；键盘焦点可见。
- [ ] `pnpm run check` 全绿。
